这里会记录一些技术笔记、踩坑记录，以及偶尔的生活碎片。写作是我一直想坚持的事情，希望这个站点能成为长期维护的自留地。

<!-- more -->

## 这个博客是怎么来的

技术栈很简单：

- **Hexo**：静态博客框架，Markdown 写作，生成纯静态页面
- **Butterfly**：主题，颜值和功能都很能打
- **GitHub + Vercel**：代码推送后自动构建部署，绑定自定义域名 `prz.best`

整个流程是：本地写 Markdown → push 到 GitHub → Vercel 自动构建 → 线上生效。
